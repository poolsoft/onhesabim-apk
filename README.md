# onHesabım — Android APK

Bu depo onHesabım uygulamasının Android kurulum paketlerini ve sürüm bilgilerini yayımlar. Kaynak kod özel depoda tutulur.

## İndir

[En son kararlı sürümü indir](https://github.com/poolsoft/onhesabim-apk/releases/latest).

Release sayfasındaki `.apk` dosyasını Android telefon veya tabletinize indirin ve kurulum ekranını açın. Android, bu kaynaktan yükleme izni ve kurulum onayı isteyebilir.

Uygulama internetsiz kullanılabilir. Güncelleme kontrolü ve APK indirme internet bağlantısı gerektirir. Mevcut release kurulumları yeni release APK'larıyla veriler silinmeden güncellenebilir.

Diğer dallardan üretilen prerelease paketleri test içindir; uygulama güncelleme kontrolünde yalnız kararlı yayınlar kullanılır.
